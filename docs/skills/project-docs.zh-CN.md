# 建立项目文档基建（中文对照）

> 对应[英文执行版](../../skills/project-docs/SKILL.md)。本稿供对照阅读，执行以英文为准；修改英文时同步更新本稿。

技能名：`project-docs`

适用于建立或重整项目文档基建。合并和归档现有文档，建立带整理守则的 README 索引，再从 `AGENTS.md` 或 `CLAUDE.md` 链接到索引，供后续任务查阅。

阅读[共用约定](conventions.zh-CN.md)。遵循项目现有文档索引中的整理守则。

先整理文档，再建立索引并接入项目的代理指令。如果只要求建立或更新索引，查看现有文档后，将改动范围限于[索引](#建立文档索引)。

1. 在请求范围内检查相关文档、目录及其引用，包括代码、测试、脚本、配置和封存工件中的使用方。合并、移动或删除前，明确用途、读者、状态、权威来源和独有内容。
2. 根据内容和引用比较用途重叠的文档或目录，沿用合适的主题结构。合并、移动、重命名、归档或删除现有文档或目录前，集中列出拟议变更，说明保留什么、内容移到哪里、哪些引用会受影响。无法更新的引用也列入方案，在移动相关文档前与用户确认处理方式。先询问用户，等确认后再执行。用户已明确同意的具体变更可以直接执行。
3. 将重叠文件收敛为一个持续维护的版本，承接独有的有效内容。依据已核实的来源修订过时说明和混乱结构。
4. 仍有现行用途的文档留在原处继续维护，按需归档其中值得回查的旧内容。就地更新过时指引，并从现行文档链接到历史记录。整份文档已停用且值得保留时，先把仍有效的结论和待办事项纳入现行记录，再移入所属主题的归档。保留理解归档内容所需的上下文，沿用既有归档命名，记录日期、原因和替代文档（如有）。结束旧计划前应用共用的方向变更规则。
5. 更新受影响的索引条目、引用链接、文件使用方和工作入口，让它们直达各自引用的内容。修复迁移内容中的相对链接。整篇迁移后，清理旧路径遗留的副本、占位文件和跳转文件，再移除已清空的重复目录。
6. [建立文档索引](#建立文档索引)，再[接入代理指令](#接入代理指令)。适当时从根 README 链接到索引。

大幅修订时，按受众配合 `project-docs-human` 或 `project-docs-agent` 完成改写。单独写作不需要整理整个仓库。

核查改动过的内容和链接、受影响的文件使用方，确认独有的有效内容未丢失、重复的现行版本已收敛。确认现行文档没有重复或被取代的执行段落。核对迁移内容的引用能直达归档位置，当前工作仍能从原有入口找到。汇报改动及重要未知事项。

## 建立文档索引

沿用项目已有的文档索引，缺失时创建 `docs/README.md`。索引包含简短标题、关键文档入口和整理守则。详细说明和任务进度留在链接指向的文档里。

- 读者需要完成常见任务、接续当前工作或查找经常用到的权威资料时，才在索引里放直达链接。用途重叠的条目合并。草稿、验证证据和单条历史记录等配套资料，从相关现行文档或已有专题索引链接。
- 用相对路径链接到现行文档，最常用的入口放在前面。链接名称按读者要找的内容来写，名称说不清时加一句用途说明。
- 按用途分组能让索引更容易查阅时，为每组加一个标题和一张表。每张表按读者找文档时需要的信息选择列。
- 整理范围限于单个主题时，更新现有索引中受影响的条目。

需要参考分组表格和守则引用块时，查看[随技能附带的文档索引示例](../../skills/project-docs/references/index-example.md)，按目标项目的需要调整版式和链接。

保留项目已有的整理守则。索引缺少守则时，用项目的文档语言加入下方的[守则](#文档整理守则)，把标题和条目放在同一个 Markdown 引用块内。从索引逐个打开受影响的链接，确认能到达预期的现行文档。

> ### 文档整理守则
>
> - **收尾前同步文档。** 项目的实际行为、已确认的决定或计划状态变化时，检查本次工作影响到的文档。按已核实的信息就地更新过时的说明、状态或下一步。
> - **保持文档简洁有效。** 优先修订合适的现有文档，确有独立用途时才新建。保留读者需要的事实、约束和步骤。每项事实在一处维护，其他文档按需链接到权威来源。
> - **归档值得回查的旧内容。** 仍在使用的文档留在原处维护，按需归档旧内容。整份文档已停用且值得保留时，再整篇归档。更新被迁移内容的引用，使其直达归档位置。
> - **精简索引入口。** 索引直达常见任务、当前工作和常用规则所需的文档，配套资料从相关文档链接。文档合并、移动或归档后，更新或移除对应条目，修复受影响的引用并核对去向。

## 接入代理指令

更新目标项目已有的项目级 `AGENTS.md` 和 `CLAUDE.md`。当前工具的项目指令文件缺失时，在项目根目录创建对应文件。Codex 用 `AGENTS.md`，Claude Code 用 `CLAUDE.md`。

用项目的文档语言添加简短的「项目文档指南」，已有文档入口时就地更新。用相对路径链接到索引。

## 示例

`todo.md` 持续作为当前工作的入口。已完成事项逐渐积累后，将值得回查的条目移入所属主题的归档，在 `todo.md` 末尾留一条简短的历史索引。沿用项目已有的路径和归档命名。

```text
docs/
├── README.md                  # 文档入口
└── todo/
    ├── todo.md                # 当前工作及其历史索引
    └── archive/
        └── past-work.md       # 值得回查的已完成事项
```
