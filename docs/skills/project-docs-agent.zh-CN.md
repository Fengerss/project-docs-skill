# 编写 AI 工作文档（中文对照）

> 对应[英文执行版](../../skills/project-docs-agent/SKILL.md)。本稿供对照阅读，执行以英文为准；修改英文时同步更新本稿。

技能名：`project-docs-agent`

适用场景：编写、更新和审阅面向 AI 的执行计划、任务交接和工作记录。当 AI 需要具体下一步、验证细节或足够的当前上下文以恢复项目工作时使用。

阅读[共用约定](conventions.zh-CN.md)。

- 阅读已有任务上下文，链接约束当前工作的项目文档，说明目标、范围和完成条件。
- 复用当前工作记录，将当前任务、最后核实的状态、阻塞与下一步放在历史背景之前。对时效性进展记录观察时点，区分记录快照与恢复工作时仍需重新核验的事实。
- 明确下一步操作和必需检查。对中断或运行中的任务，指出首先核验什么、已有状态来源或检查点在哪里，以及如何根据核验结果，在适用的授权与边界内选择等待、续接或停止。对照现有脚本和配置核查记录的命令，保留需要人作决定的问题。
- 将已核实的工作、验证结果与相关历史提炼为聚焦的条目。保留影响当前决策的历史结论，详情链接到已有记录；下一步所需资料的引用放在对应操作旁。
- 工作有实质变化时更新记录。区分实现与验证，替换过时的下一步，应用共用方向变更规则，不逐轮追加交互流水账。

重新核查引用和命令，汇报改动及重要未知事项。
