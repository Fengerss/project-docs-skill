> ### 文档整理守则
>
> - **收尾前同步文档。** 功能或使用方式变化时，更新受影响的说明。英文技能或共用约定变更时，在同一次修改中同步中文对照。
> - **保持文档简洁有效。** 优先更新已有文档，每项事实在一处维护。保留读者需要的信息，其他入口按需链接到原文。
> - **归档值得回查的旧内容。** 仍在使用的文档留在原处维护，按需归档旧内容。整份文档已停用且值得保留时，再整篇归档。更新被迁移内容的引用，使其直达归档位置。
> - **精简索引入口。** 索引直达常见任务、当前工作和常用规则所需的文档，配套资料从相关文档链接。文档合并、移动或归档后，更新或移除对应条目，修复受影响的引用并核对去向。
